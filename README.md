# Shiriniko — نسخه اولیه

این پروژه یک نمونه اولیه و نمایشی از صفحه اصلی فروشگاه خوراکی‌های خارجی شیرینیکو است.

## فایل‌ها
- `index.html`: صفحه اصلی، ظاهر، جست‌وجو، دسته‌بندی و سبد خرید آزمایشی در یک فایل.

## اجرا با گوشی
می‌توانید فایل `index.html` را در یک ویرایشگر کد موبایل باز کنید یا آن را در مخزن GitHub خود بارگذاری کنید. برای مشاهده مستقیم فایل محلی، از برنامه‌ای استفاده کنید که پیش‌نمایش HTML داشته باشد.

## نکته مهم
محصول‌ها، تخفیف‌ها و قیمت‌ها نمونه‌اند. این نسخه هنوز سرور، پایگاه داده، پنل مدیریت، ثبت سفارش واقعی یا درگاه پرداخت ندارد. پرداخت واقعی تا زمان پیاده‌سازی و آزمایش امن سمت سرور فعال نخواهد شد.
